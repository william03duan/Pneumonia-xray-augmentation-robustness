# Local dataset

The full `pneumoniamnist_128.npz` file is intentionally excluded from Git because it is a binary source dataset. Download the 128 by 128 PneumoniaMNIST archive from the official [MedMNIST v2 project](https://medmnist.com/) and place it at:

```text
data/pneumoniamnist_128.npz
```

The tracked `data_preview/` folder contains a small image grid and split summary that can be viewed directly on GitHub.
